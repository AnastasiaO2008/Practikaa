# Исправления Language Bloom (Yii2)

## Что изменено
- Регистрация и вход теперь проверяются сервером и работают с таблицей `account`.
- Пароль сохраняется только как безопасный хеш.
- В `account` добавлена роль `user` / `admin`.
- Добавлен API для сохранения и загрузки слов из таблиц `language` и `words`.
- Добавлена административная панель `/admin/index`.
- CRUD языков и слов; существующие CRUD пользователей и истории доступны только администратору.
- Списки CRUD используют существующую пагинацию и сортировку из ActiveDataProvider.
- Добавлена миграция, исправляющая тип поля пароля и создающая администратора.

## Запуск через OpenServer
1. Сделай резервную копию своей папки проекта и базы данных.
2. В phpMyAdmin проверь, что создана база `dnevnik`, кодировка `utf8mb4`.
3. Проверь `config/db.php`: `username` и `password` должны совпадать с настройками MySQL в OpenServer. В текущем файле оставлены исходные значения `root` / `root`; если у тебя MySQL без пароля, укажи пустую строку `''`.
4. Открой консоль OpenServer в корне проекта (там, где файл `yii`) и выполни:
   `php yii migrate`
5. Подтверди выполнение миграции ответом `yes`.
6. Открой сайт и зарегистрируй обычного пользователя через окно регистрации.

## Администратор
- Почта: `admin@languagebloom.local`
- Пароль: `Admin123!`
- Панель: `/admin/index`

Сразу после первого входа поменяй пароль администратора. Не используй эти тестовые данные на публичном сервере.

## Важно
- Миграция `m261112_081000_fix_account_and_seed_admin` рассчитана на то, что исходные миграции уже выполнены и таблица `account` существует.
- Старые пароли из INT нельзя безопасно превратить в хеш автоматически. Для таких пользователей потребуется сброс пароля/повторная регистрация.
- Фронтенд оставляет `localStorage` только для отображения имени пользователя; он больше не хранит пароль и не является источником авторизации.
