# Обновление авторизации Language Bloom

1. Сохрани резервную копию базы данных и проекта.
2. Распакуй содержимое каталога `basic1` поверх текущего проекта в OpenServer.
3. Убедись, что применены миграции: в консоли проекта выполни `php yii migrate`.
   Особенно важна `m261112_081000_fix_account_and_seed_admin`: она переводит поле
   `account.password` в VARCHAR(255), чтобы помещался хеш, и добавляет `role`.
4. При успешном входе пользователь попадает в `/site/profile`.
5. Аватар справа ведёт на страницу входа для гостя и в личный профиль для
   авторизованного пользователя. Войти/зарегистрироваться показываются только гостям.
6. Старые пароли, записанные в БД обычным текстом или числом, при первом
   успешном входе автоматически заменяются хешем. Для уже хешированных
   паролей применяется стандартная проверка Yii2.
7. После замены файлов обнови браузер с Ctrl+F5, чтобы сбросить кэш JS.

**Важно:** в форме входа используется email из `account.mail`, а не имя из
`account.name`. Если исходный пароль был изменён или повреждён до этого
обновления, восстановить его без сброса невозможно.
